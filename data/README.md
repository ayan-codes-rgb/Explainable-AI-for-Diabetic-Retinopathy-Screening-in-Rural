# data/

Datasets live on the shared Drive, NOT in git. Download them here:

```
data/
├── IDRiD/          images + grades + pixel-level lesion masks
├── APTOS2019/      images + grades
├── DRIVE/          vessel ground truth
└── e-ophtha/       microaneurysm + exudate ground truth
```

Everything in this folder except this README is gitignored. If `git status`
ever shows a dataset file as staged, stop and fix it before committing.
