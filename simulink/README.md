# simulink

**Owner: M6**

Simulink model of the telemedicine pipeline: acquisition rate, bandwidth, processing throughput, review capacity. Outputs a resource-allocation figure for a 100k-patient/year district programme.

Must fill in the shared result struct: nothing — this is a standalone model, not part of `analyzeImage()`

Read `../common/README.md` before writing any image code. Use `loadFundus()`, never `imread()`.
